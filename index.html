Governed Snowflake Cortex SQL Query

Generated by Snowflake Cortex Semantic Compiler v2.4:
SELECT 
    delivery_partner,
    COUNT(delivery_id) AS total_shipments,
    SUM(CASE WHEN delayed = 'yes' THEN 1 ELSE 0 END) AS delayed_shipments,
    ROUND(SUM(CASE WHEN delayed = 'yes' THEN 1 ELSE 0 END) * 100.0 / COUNT(delivery_id), 1) AS delay_percentage,
    ROUND(AVG(delivery_cost), 2) AS avg_cost_inr
FROM 
    SNOWFLAKE_SC_DB.SEMANTIC.TMS_DELIVERY_LOGISTICS
WHERE 
    region IN ('west', 'central', 'south', 'north', 'east')
GROUP BY 
    delivery_partner
ORDER BY 
    delay_percentage DESC;
